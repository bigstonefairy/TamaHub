# 하드웨어 / 케이스 메모

대상 보드: **Waveshare ESP32-S3-Touch-AMOLED-1.75**
(16MB Flash / 8MB OPI PSRAM / 466×466 AMOLED)

이 문서는 멀티게임 빌드에 직접 관련된 부분만 정리한 것입니다. 전체 회로도와
치수는 Waveshare 공식 저장소의 문서를 따르세요.

---

## 1. 핀 맵 (펌웨어가 사용하는 값)

| 기능 | 신호 | GPIO |
|---|---|---|
| AMOLED (CO5300, QSPI) | SDIO0 / SDIO1 / SDIO2 / SDIO3 | 4 / 5 / 6 / 7 |
| | SCLK / CS / RESET | 38 / 12 / 39 |
| 터치 (CST9217, I2C) | SDA / SCL | 15 / 14 |
| | INT / RESET | 11 / 40 |
| PMU (AXP2101, I2C) | SDA / SCL | 15 / 14 |
| RTC (PCF85063, I2C) | SDA / SCL | 15 / 14 |
| 오디오 (ES8311) | MCLK / BCLK / WS / DO / DI | 42 / 9 / 45 / 8 / 10 |
| | PA enable | 46 |
| microSD (SD_MMC 1-bit) | CLK / CMD / DATA | 2 / 1 / 3 |
| 아래쪽 버튼 | **BOOT** | **0** |
| 위쪽 버튼 | PWR (AXP2101 / TCA9554 EXIO4) | GPIO 아님 |

- `pin_config.h`가 허브와 두 게임에 동일하게 들어 있습니다.
- 부팅 중 GPIO0을 누르고 있으면 **ROM 다운로드 모드**로 들어갑니다. 게임 전환은
  반드시 게임이 뜬 뒤에 2초 롱프레스하세요.
- PWR은 4초 이상 누르면 AXP2101이 하드웨어적으로 전원을 끊습니다. 펌웨어는 이
  동작을 바꾸지 않습니다(전원 차단은 안전 장치로 남겨 둠).

---

## 2. 전원 / RTC

- 패널 전원(BLDO1, 3.3V)은 PMU가 제어합니다. 펌웨어는 `gfx->begin()` **전에**
  `setBLDO1Voltage(3300)` + `enableBLDO1()`을 호출합니다. 배터리가 완전히
  방전된 뒤에는 이 레일이 꺼져 있어 화면이 검게 보일 수 있습니다.
- PCF85063은 백업 전지/슈퍼캡이 있어야 전원을 뺀 동안 시간을 유지합니다. 백업이
  없으면 부팅 시각이 2000년대로 돌아가고, 두 게임 모두 오프라인 진행을 적용하지
  않습니다(업스트림과 동일). 케이스에 넣을 때 RTC 백업 전지를 함께 넣는 것을
  권장합니다.
- `resumeAt`(일시정지)도 RTC가 유효할 때만 기록됩니다.

---

## 3. microSD

- 두 게임 모두 **SD_MMC 1-bit** 모드로 마운트합니다. FAT32로 포맷된 카드를
  사용하세요.
- 스프라이트 경로가 게임별로 분리되어 있습니다.

  ```
  /tamapoke/mons/…
  /tamadigi/mons/…
  ```

- TamaPoke는 마운트 실패 시 더 이상 카드를 포맷하지 않습니다.
- 카드를 뺐다 넣었을 때는 전원을 껐다 켜는 것이 가장 확실합니다.

---

## 4. 케이스(3D 프린트) 메모

- **MagSafe 무선충전 코일**은 보드 후면 중앙에 두고, 충전 코일과 배터리 사이에
  금속 부품/나사를 두지 마세요. 발열과 충전 효율에 직접 영향을 줍니다.
- AMOLED는 베젤 안쪽으로 0.5~1mm 정도 recess를 두면 먼지가 덜 끼고 눌림도
  줄어듭니다. 화면 위에 두꺼운 투명판을 올리면 터치 감도가 떨어집니다.
- 아래쪽 버튼은 **BOOT/GPIO0**를 누르도록 설계합니다. 스위치 접점이 보드의
  버튼을 직접 누르는 구조라면 스트로크 0.3~0.5mm, 복원력 있는 실리콘/스프링을
  사용하세요.
- 위쪽 버튼(PWR)은 전원 전용으로 남겨 두는 것이 안전합니다. 케이스에서 PWR을
  전환 버튼으로 쓰고 싶다면 4초 하드웨어 차단과 충돌하지 않도록 별도 GPIO 택트
  스위치를 추가하는 편이 낫습니다.
- USB-C 포트는 케이스 안쪽으로 1~2mm 들어가도 케이블이 닿도록 깔때기 형태를
  두는 것이 좋습니다.
- 배터리와 보드 사이에 얇은 절연 테이프/폼을 넣어 쇼트를 막으세요.

## 5. 플래싱 요약

| 파트 | 주소 |
|---|---|
| bootloader | `0x0` |
| partition table | `0x8000` |
| TamaHub (factory) | `0x20000` |
| TamaPoke (ota_0) | `0x320000` |
| TamaDigi (ota_1) | `0x620000` |
| 추가 슬롯 (ota_2) | `0x920000` |

- 최초 설치: 웹 설치 프로그램에서 **Erase** 포함 전체 설치.
- 게임만 업데이트: 해당 슬롯만 기록 → NVS와 다른 게임은 유지.
- **Arduino IDE의 Upload 버튼은 사용 금지**: 앱을 `0x10000`, `boot_app0.bin`을
  `0xE000`에 써서 NVS를 덮어씁니다. 컴파일 전용으로만 사용하세요.

자세한 절차는 [`../README.md`](../README.md) 참고.
