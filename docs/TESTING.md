# 기기 테스트 체크리스트

빌드는 통과했지만 실제 보드에서 확인해야 할 항목입니다. 위에서부터 순서대로
진행하세요. 각 단계는 실패했을 때 원인을 좁힐 수 있도록 독립적으로 설계했습니다.

시리얼 모니터: **115200 baud**, USB CDC.

---

## 0. 첫 설치

- [ ] 기존 펌웨어의 세이브를 백업했다 (TamaDigi `EXPORT`, TamaPoke 저장).
- [ ] 웹 설치 프로그램에서 **Erase 포함 전체 설치**를 실행했다.
- [ ] 설치 후 자동 재부팅되고 **TamaHub**가 뜬다.
- [ ] 시리얼에 `=== TamaHub ===`, `hub v1.0`, 슬롯 3개가 보인다.
      Poke/Digi는 `ready`, Extra는 `EMPTY`로 표시된다.

기대 로그:

```
=== TamaHub ===
hub v1.0
  1 POKEMON      @0x320000 ready
  2 DIGIMON      @0x620000 ready
  3 EXTRA SLOT   no partition
```

## 1. 허브 입력

- [ ] 카드를 터치하면 `STARTING` → 해당 게임으로 재부팅.
- [ ] BOOT를 짧게 누르면 선택이 위/아래로 이동.
- [ ] BOOT를 1.2초 이상 누른 뒤 떼면 선택한 게임 실행.
- [ ] 빈 Extra 카드를 선택하면 `SLOT IS EMPTY`가 뜨고 허브로 돌아온다.
- [ ] 시리얼 `1` / `2` / `SLOTS`가 동작한다.

## 2. 게임 실행 / 자동 재개

- [ ] Pokémon으로 부팅되고 화면/터치/소리가 정상이다.
- [ ] 전원을 껐다 켜면 **허브를 거치지 않고 Pokémon으로 바로** 부팅된다.
- [ ] Digimon도 동일하게 동작한다.

## 3. 게임 전환 / 저장

- [ ] 게임 중 BOOT를 2초 누르면 `SAVING` → `SAVED / release the button`.
- [ ] **손을 떼면** 재부팅되어 허브로 돌아온다. (떼기 전에는 멈춰 있음)
- [ ] 다시 들어갔을 때 나이/스탯/도감/파티가 유지된다.
- [ ] 전환 직후 게임의 `offline: N min` 로그가 **0 또는 매우 작은 값**이다.
      (다른 게임에 있던 시간이 오프라인 진행으로 들어가면 안 됨)

## 4. 오프라인 진행 / 일시정지

- [ ] 게임을 저장하고 전원을 10분 이상 꺼 둔다.
- [ ] 다시 켜면(마지막 게임 자동 부팅) 약 10분의 오프라인 진행이 적용된다.
- [ ] Poke → 허브 → Digi로 전환한 뒤 Poke로 돌아오면, 그 사이 시간이
      Poke의 오프라인 진행으로 적용되지 않는다.
- [ ] 허브에서 오래 머문 뒤 전원을 끄면 그 시간은 일시정지로 처리된다
      (알려진 제한, `README.md` 참고).

## 5. SD 카드

- [ ] `/tamapoke/mons`와 `/tamadigi/mons`를 각각 준비했다.
- [ ] 각 게임에서 스프라이트/도감 썸네일이 보인다.
- [ ] 카드를 빼고 부팅해도 게임이 멈추지 않고, 카드 관련 안내만 뜬다.
- [ ] 카드를 다시 넣고 전원을 껐다 켜면 스프라이트가 돌아온다.
- [ ] TamaDigi의 `SD ... FORMAT`은 **일부러 쓰지 않는다** (카드 전체가 지워짐).

## 6. 복구 / 예외

- [ ] 게임 중 전원을 강제로 뽑아도 다음 부팅에서 세이브가 유지된다
      (마지막 자동 저장 시점 기준).
- [ ] 허브 슬롯을 일부러 비운 상태에서 게임의 BOOT 2초를 누르면
      `HUB MISSING / reinstall from a PC`가 뜨고 게임이 계속 실행된다.
- [ ] 기기를 ROM 다운로드 모드로 만들었을 때 웹 설치 프로그램으로 복구된다.
- [ ] 부팅 루프가 나면 `erase_flash` 후 전체 재설치로 복구된다.

## 7. 24시간 soak

- [ ] 24시간 켜 둔 뒤에도 힙 고갈/재부팅이 없다.
- [ ] 반복 전환 20회 후에도 파티션/세이브가 정상이다.
- [ ] 배터리 잔량 표시와 USB 표시가 실제와 맞는다.
- [ ] (선택) RTC 백업 전지를 넣고 전원을 뺐다 켜서 시각이 유지되는지 확인.

---

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 검은 화면 | 부팅 중 BOOT를 눌렀는지, PMU BLDO1 로그, USB 재연결 |
| 카드가 `NOT INSTALLED` | 해당 슬롯에 앱이 있는지, 전체 설치를 했는지 |
| 허브로 안 돌아옴 | 2초 유지 후 **완전히 떼기**, 시리얼의 `multiboot:` 로그 |
| 세이브가 사라짐 | Erase 전체 설치 여부, NVS(`0x9000`) 보존 여부 |
| 스프라이트 없음 | SD 루트와 게임별 `mons` 경로, `LS` 명령 |
