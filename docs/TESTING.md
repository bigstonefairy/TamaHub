# 기기 테스트 체크리스트

빌드는 통과했지만 실제 보드에서 확인해야 할 항목입니다. 위에서부터 순서대로
진행하세요. 각 단계는 실패했을 때 원인을 좁힐 수 있도록 독립적으로 설계했습니다.

시리얼 모니터: **115200 baud**, USB CDC.

---

## 0. 첫 설치

- [ ] 기존 펌웨어의 세이브를 백업했다 (TamaDigi `EXPORT`, TamaPoke 저장).
- [ ] 기존 사용자라면 **일괄 설치 (세이브 유지)** 로 Erase 없이 올렸다.
- [ ] 슬롯 배치를 바꾼 뒤 **설치 계획**의 순서·주소가 바뀐 배치와 일치하고,
      **일괄 설치 시작** 한 번으로 모든 파트가 기록됐다(포트 재선택 없음).
- [ ] 새 기기라면 웹 설치 프로그램에서 **Erase 포함 전체 설치**를 실행했다.
- [ ] 설치 후 자동 재부팅되고 **TamaHub**가 뜬다.
- [ ] 시리얼에 `=== TamaHub ===`, `hub v1.2`, 슬롯 5개가 보인다.
      배치한 앱은 `ready v<버전>`, 빈 슬롯은 `EMPTY`로 표시된다.

기대 로그(기본 배치):

```
=== TamaHub ===
hub v1.2
  1 CLOCK        @0x220000 ready v1.1.1
  2 POKEMON      @0x420000 ready v1.38.0
  3 DIGIMON      @0x620000 ready v1.1.1
  4 NAV          @0x820000 ready v1.0.0
  5 EMPTY        @0xa20000 EMPTY
```

## 1. 허브 입력

- [ ] 카드를 터치하면 `STARTING` → 해당 앱으로 재부팅.
- [ ] BOOT를 짧게 누르면 선택이 아래로 이동.
- [ ] BOOT를 1.2초 이상 누른 뒤 떼면 선택한 앱 실행.
- [ ] 빈 슬롯을 선택하면 `SLOT IS EMPTY`가 뜨고 허브로 돌아온다.
- [ ] 시리얼 `1`–`5`, `SLOTS`가 동작한다.

## 2. 앱 실행 / 자동 재개

- [ ] Pokémon으로 부팅되고 화면/터치/소리가 정상이다.
- [ ] 전원을 껐다 켜면 **허브를 거치지 않고 Pokémon으로 바로** 부팅된다.
- [ ] Digimon/Naruto/Clock도 동일하게 동작한다.
- [ ] TamaClock이 RTC 시각을 표시하고 `SET=`/`TIME=`/`STATUS`가 동작한다.

## 3. 앱 전환 / 저장 / 뒤로가기

- [ ] 앱 중 BOOT를 2초 누르면 `SAVING` → `SAVED / release the button`.
- [ ] **손을 떼면** 재부팅되어 허브로 돌아온다. (떼기 전에는 멈춰 있음)
- [ ] 다시 들어갔을 때 나이/스탯/도감/파티가 유지된다.
- [ ] 전환 직후 게임의 `offline: N min` 로그가 **0 또는 매우 작은 값**이다.
      (다른 앱에 있던 시간이 오프라인 진행으로 들어가면 안 됨)
- [ ] BOOT를 **짧게** 누르면 한 화면 뒤로 간다. (Poke는 오버레이만, 전투/미니게임 유지)
- [ ] TamaClock에서 BOOT를 짧게 누르면 12/24시간이 전환된다.

## 4. 오프라인 진행 / 일시정지

- [ ] 게임을 저장하고 전원을 10분 이상 꺼 둔다.
- [ ] 다시 켜면(마지막 게임 자동 부팅) 약 10분의 오프라인 진행이 적용된다.
- [ ] Poke → 허브 → Digi로 전환한 뒤 Poke로 돌아오면, 그 사이 시간이
      Poke의 오프라인 진행으로 적용되지 않는다.
- [ ] 허브에서 오래 머문 뒤 전원을 끄면 그 시간은 일시정지로 처리된다
      (알려진 제한, `README.md` 참고).

## 5. SD 카드

### 웹 업로드

- [ ] 허브 화면에서 **보드 연결**을 누르면 "게임을 확인할 수 없습니다"로 끝나고,
      연결이 정리된다. (멈추지 않음)
- [ ] TamaPoke 실행 중 연결하면 화면에 `TamaPoke 연결됨`이 뜨고 **Pokémon 버튼만** 활성화된다.
- [ ] TamaDigi 실행 중 연결하면 **Digimon 버튼만**, TamaNaruto 실행 중에는 **Naruto 버튼만** 활성화된다.
- [ ] 연결 시 `SD: READY · NNNMB free`와 **쓰기 테스트 OK**가 표시된다.
- [ ] 쓰기 금지/불량 카드에서는 `SD: 쓰기 실패`가 뜨고 업로드 버튼이 비활성화된다.
- [ ] **PC에서 FAT32로 새로 포맷한 카드**를 넣고 연결했을 때 `SD: READY` +
      쓰기 테스트 OK가 나온다. (상위 폴더 `/tamapoke` 등이 자동 생성됨)
- [ ] SD가 인식되지 않으면 `SD: 인식 안 됨`이 표시되고 업로드 버튼이 비활성화된다.
- [ ] **SD 마운트 / 포맷** 후 `SD: READY`로 바뀌면 업로드 버튼이 활성화된다.
      (정상 카드는 데이터 유지, 인식 불가 카드만 포맷)
- [ ] **스프라이트 비우기**로 현재 게임의 SD 폴더가 비워지고 여유 공간이 늘어난다.
- [ ] TamaPoke가 실행 중일 때 **Pokémon 스프라이트 넣기**. 기본+Gen3 **773개**,
      약 105MB가 전송되고, 재부팅 후 스프라이트/도감이 보인다.
- [ ] TamaDigi가 실행 중일 때 **Digimon 스프라이트 넣기**. 175개(공유
      `thumbs.bin` 1개 포함)가 전송되고, 재부팅 후 그림이 보인다.
- [ ] TamaNaruto가 실행 중일 때 **Naruto 스프라이트 넣기**. 4개 마을 팩이
      병합된 67개가 전송되고, 재부팅 후 그림이 보인다.
- [ ] 업로드 중 USB를 뽑으면 **영원히 멈추지 않고** 실패로 끝나며,
      로그에 `블록 N ACK 실패` 또는 `PUT OK 응답 없음`이 표시된다.
- [ ] USB를 다시 연결하고 같은 버튼을 누르면 이미 보낸 파일을 건너뛰고 이어서 전송한다.
- [ ] SD를 포맷한 뒤 **진행 기록 초기화**를 누르면 처음부터 다시 보낸다.

### 수동 준비

- [ ] `/tamapoke/mons`, `/tamadigi/mons`, `/tamaruto/mons`를 각각 준비했다.
- [ ] 각 게임에서 스프라이트/도감 썸네일이 보인다.
- [ ] 카드를 빼고 부팅해도 게임이 멈추지 않고, 카드 관련 안내만 뜬다.
- [ ] 카드를 다시 넣고 전원을 껐다 켜면 스프라이트가 돌아온다.
- [ ] TamaDigi의 `SD ... FORMAT`은 **일부러 쓰지 않는다** (카드 전체가 지워짐).

## 6. 복구 / 예외

- [ ] 게임 중 전원을 강제로 뽑아도 다음 부팅에서 세이브가 유지된다
      (마지막 자동 저장 시점 기준).
- [ ] 허브 슬롯을 일부러 비운 상태에서 게임의 BOOT 2초를 누르면
      `HUB MISSING / reinstall from a PC`가 뜨고 게임이 계속 실행된다.
- [ ] 기기를 ROM 다운로드 모드로 만들었을 때 웹 설치 프로그램으로 복구된다.
- [ ] 부팅 루프가 나면 `erase_flash` 후 전체 재설치로 복구된다.

## 7. 언어 (English / 한국어)

- [ ] **TamaPoke**: 시계 화면의 언어 알약이 `EN >`이고, 탭하면 `KO >`로 바뀌며
      화면이 즉시 한국어로 다시 그려진다.
- [ ] **TamaDigi**: 설정의 `LANG  EN >` 행을 탭하면 `LANG  KO >`가 된다.
- [ ] 한국어에서 상태 문구/버튼/대화상자/전투 로그/도감과 **종족 이름**이 한글이다.
      (Poke 386종, Digi 87종)
- [ ] 긴 한글 이름과 문구가 잘리거나 상자를 넘치지 않는다. 좁은 자리에서는
      자동으로 작아진다.
- [ ] 전투 로그가 한글 음절 중간에서 잘리지 않고 3줄로 나뉜다.
- [ ] 전원을 껐다 켜도 선택한 언어가 유지된다 (NVS `lang2`).
- [ ] 영어로 되돌리면 기존 화면과 픽셀 단위로 같다 (폰트/좌표 변화 없음).
- [ ] 기술 이름과 도움말 화면은 두 언어 모두 영어로 나온다.
- [ ] 한국어 상태로 전투 10회 + 30분 플레이 후 힙이 계속 줄지 않는다.
- [ ] TamaDigi 전투/탐험 배경이 바이옴·시간대에 맞게 그려지고 깜빡이지 않는다.
      (내장 배경 이미지가 없어졌으므로 첫 전투 화면에서 확인)

## 8. TamaClock v1.1

- [ ] 원 테두리가 화면 끝(반지름 224)에 가깝고, 맨 아래 안내 문구가 원 밖으로
      잘리지 않는다.
- [ ] 디지털 시계 숫자가 화면 폭을 크게 쓰고 한눈에 읽힌다 (12시/24시 모두).
      숫자 위쪽 모서리가 원 밖으로 잘리지 않고, 시계 블록이 중앙보다 살짝 위에 있다.
- [ ] 상단에 배터리 아이콘과 `%`가 표시되고, USB를 꽂으면 초록색 + 번개로 바뀐다.
- [ ] 날짜가 오늘 날짜로 표시된다. 시각은 RTC와 같고, 자정이 지나면 날짜가 넘어간다.
- [ ] 아래 `SWIPE / TAP / HOLD / PWR` 안내가 작게, 원 안에 들어온다.
- [ ] 위/아래 스와이프는 `DIGITAL ONLY` 토스트만 띄우고 화면은 디지털로 유지된다.
- [ ] 길게 누르면 테마 색이 7가지로 순환하고 링·숫자·장면 색이 함께 바뀐다.
- [ ] 톡 누르면 12/24시간이 바뀐다.
- [ ] PWR 짧게 누르면 화면이 꺼지고, 다시 누르거나 화면을 터치하면 켜진다.
- [ ] 포켓몬/디지몬/마리오/젤다 화면이 더 이상 나타나지 않는다
      (시리얼 `FACE=1`도 디지털로 남는다).
- [ ] 재부팅 후에도 색/12·24시간 설정이 유지되고, 예전에 저장한 `face` 값 때문에
      테마 화면으로 뜨지 않는다 (NVS `tamaclock`).

## 9. TamaNav v1.0

- [ ] 설치 페이지 기본 배치가 Clock / Poke / Digi / 내비이고, 내비가 `ota_3`
      (`0x820000`), 5번 슬롯(`ota_4`, `0xA20000`)이 비어 있다.
- [ ] 허브 카드에 `TamaNav v1.0.0`이 뜨고 실행하면 `PAIR YOUR PHONE` 대기 화면이 나온다.
- [ ] 폰의 BLE 스캐너에서 `TamaNav`가 보이고 서비스 `4e415600-…`가 노출된다.
- [ ] 연결하면 기기가 `HELLO`/`STATUS`를 보내고, 폰에서 30초마다 `STATUS`를 받는다.
- [ ] 16바이트 안내 패킷을 쓰면 화살표·거리·남은 시간이 즉시 바뀐다.
- [ ] 아이콘 1–18이 모두 해당 도형으로 그려지고, 원 밖으로 잘리지 않는다.
- [ ] `CLR`을 보내면 대기 화면으로 돌아간다.
- [ ] 패킷을 15초 이상 끊으면 점이 노랑으로 바뀌고 `NO LINK`가 뜨며, 값은 유지된다.
- [ ] `ARRIVE`/`OFFROUTE`에서 화면과 색이 바뀐다.
- [ ] 시리얼 `DEMO`가 폰 없이 3초마다 화면을 갱신한다.
- [ ] BOOT 짧게로 밝기가 4단계 순환하고 재부팅 후에도 유지된다 (NVS `tamanav`).
- [ ] BOOT 2초로 허브에 돌아가고, 다시 실행하면 대기 화면부터 시작한다.
- [ ] 내비 30분 + BLE 재연결 5회 후에도 힙 고갈/재부팅이 없다.
- [ ] 폰 화면이 꺼져도 동반 앱이 계속 패킷을 보낸다(배터리 최적화 예외).

## 10. 쉬움 모드 / 게임 속도 / 문구

- [ ] **TamaPoke**: 시계 화면 위쪽 줄에 `SPEED 1x`와 `EASY MODE OFF`가 보이고,
      아래 줄의 SOUND/PSAVE/LANG과 겹치지 않는다.
- [ ] TamaPoke `SPEED`를 탭할 때마다 1x → 2x → 3x → 1x로 바뀌고 강조색이 따라온다.
- [ ] TamaPoke `EASY`를 켜면 네 가지 바가 100으로 고정되고, 몇 분 지나도 줄지 않으며
      똥이 생기지 않는다.
- [ ] TamaPoke 쉬움 모드에서 어느 공격 버튼을 눌러도 **첫 턴에** 전투가 승리로 끝나고
      (급소/빗나감/무효 포함), HP 바가 0이 된 뒤 결과 화면이 `WIN`으로 뜬다.
- [ ] TamaPoke 쉬움 모드에서 `CATCH`를 누르면 전설 포함 어떤 포켓몬이든 잡힌다.
- [ ] TamaPoke 쉬움 모드에서 원정을 시작하면 곧바로 `받기` 상태가 된다.
- [ ] **TamaDigi**: 설정에서 오른쪽 호를 넘겨 3번째 페이지로 가면 `EASY MODE`와
      `SPEED` 행, 안내 두 줄이 보인다.
- [ ] TamaDigi 페이지 3의 `SPEED`는 −/+ 로 1x/2x/3x가 되고, 가운데 막대가 1/3·2/3·3/3을
      보여 준다. 1x에서 −는, 3x에서 +는 아무 일도 하지 않는다.
- [ ] TamaDigi 쉬움 모드에서 공격 기술을 한 번 쓰면 상대가 반격하기 전에 쓰러지고
      승리 처리된다. 상태 기술만으로는 끝나지 않는다.
- [ ] TamaDigi 쉬움 모드에서 야생이 도망가지 않고, 지고 나도 결과가 승리로 처리되며,
      보스전도 패배하지 않는다. 링크 대전은 상대 기기 결과를 따른다.
- [ ] 두 게임 모두 설정을 바꾼 뒤 재부팅해도 값이 유지된다
      (Poke `easy`/`gspd`, Digi `easy`/`spd`).
- [ ] 2x/3x에서 1분 안에 눈에 띄게 더 많은 틱이 돌지만, 시계·낮/밤 배경과
      TamaClock 화면은 실제 시각을 그대로 쓴다.
- [ ] 게임을 새로 시작(리셋)해도 쉬움 모드/속도 설정은 유지된다.
- [ ] **TamaPoke 메인 화면**: 이름 아래에 큰 `HH:MM` 시계가 뜨고, 상태 문구는
      그 아래로 내려와 펫 스프라이트와 겹치지 않는다. 시각은 TamaClock의 시각과 같다.
- [ ] 시계 화면에서 분을 바꿔 적용하면 메인 화면 시계도 몇 초 안에 따라온다.
- [ ] 걸음 칩은 흰 배경 없이 테두리와 글자만 있고 화면 가로 중앙에 있다.
- [ ] **기본 언어**: 새로 설치(NVS 초기화)한 기기에서 TamaPoke/TamaDigi가 한국어로
      시작한다. 기존 `lang2` 값이 있는 기기는 그 언어를 유지한다.
- [ ] **TamaPoke 한국어**: 걸음 칩이 `1234걸음`, 걸음 카드가 `오늘 1234걸음`,
      `누적 12345걸음`, 목표 행이 `5000걸음`, 원정 행이 `0/1500걸음`으로 나오고
      오른쪽 끝이 상자 밖으로 넘치지 않는다.
- [ ] **TamaDigi 한국어**: 훈련 화면 제목이 크게 보이고, 첫 행이 `공격`(능력치 카드와
      같은 말)이며, 기억 행의 `최고 N` 기록이 행 테두리와 겹치지 않는다.

## 11. 24시간 soak

- [ ] 24시간 켜 둔 뒤에도 힙 고갈/재부팅이 없다.
- [ ] 반복 전환 20회 후에도 파티션/세이브가 정상이다.
- [ ] 배터리 잔량 표시와 USB 표시가 실제와 맞는다.
- [ ] (선택) RTC 백업 전지를 넣고 전원을 뺐다 켜서 시각이 유지되는지 확인.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 검은 화면 | 부팅 중 BOOT를 눌렀는지, PMU BLDO1 로그, USB 재연결 |
| 카드가 `NOT INSTALLED` | 해당 슬롯에 앱이 있는지, 전체 설치를 했는지 |
| 허브로 안 돌아옴 | 2초 유지 후 **완전히 떼기**, 시리얼의 `multiboot:` 로그 |
| 세이브가 사라짐 | Erase 전체 설치 여부, NVS(`0x9000`) 보존 여부 |
| 스프라이트 없음 | SD 루트와 게임별 `mons` 경로, `LS` 명령 |
