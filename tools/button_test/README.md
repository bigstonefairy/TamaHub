# 아래쪽 버튼 확인 (BOOT vs PWR)

이 스케치를 플래시한 뒤, **케이스의 아래쪽 버튼을 눌렀을 때 어느 줄이 초록색으로 바뀌는지** 보면 됩니다.

> **먼저 코드 없이 확인하는 방법**
>
> TamaPoke/TamaDigi가 실행 중일 때 아래쪽 버튼을 **4초 이상** 눌러 보세요.
> - 전원이 꺼지면 → **PWR**
> - 전원이 안 꺼지면 → **PWR가 아님** (BOOT이거나 버튼이 연결되지 않음)
>
> PWR은 펌웨어와 무관하게 AXP2101이 4초에 하드웨어로 차단합니다.
>
> 그다음, 아래쪽 버튼을 **누른 채로 USB를 꽂아** 전원을 넣어 보세요.
> - 게임이 안 켜지고 화면이 검은 채로 있으면 → **BOOT** (다운로드 모드)
> - 게임이 정상 부팅되면 → 버튼이 보드까지 **연결되지 않았을 가능성**
>
> 이 두 가지로 거의 판별됩니다. 확실하게 하려면 아래 테스트 스케치를 사용하세요.

## 0. Arduino IDE 설치 (처음 하는 경우)

`.ino` 파일은 더블클릭으로 열리지 않을 수 있습니다. **Arduino IDE**가 필요합니다.

1. https://www.arduino.cc/en/software 에서 **Arduino IDE 2.x**를 내려받아 설치
2. Arduino IDE 실행
3. `파일(File) → 열기(Open)...` 또는 `Ctrl+O`
4. 이 폴더의 **`button_test.ino`**를 선택
   - 경로: `tools/button_test/button_test.ino`
   - 폴더째로 열려야 하며, `pin_config.h` 탭이 함께 보이면 정상

### ESP32 보드 설치

1. `파일 → 환경 설정(Preferences)`
2. **Additional boards manager URLs**에 아래 주소 입력:
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. `도구 → 보드 → 보드 매니저...`
4. `esp32` 검색 → **esp32 by Espressif Systems** 설치 (3.3.11 권장)

### 라이브러리 설치

`도구 → 라이브러리 관리...`에서:

- `GFX Library for Arduino` → **1.6.7** 설치
- `XPowersLib` → **0.3.3** 설치

## 1. 보드 설정

- 보드: `ESP32S3 Dev Module`
- Flash Size: `16MB (128Mb)`
- PSRAM: `OPI PSRAM`
- Partition Scheme: `16M Flash (3MB APP/9MB FATFS)`
- USB CDC On Boot: `Enabled`
- Port: 보드가 연결된 `COMx`

## 2. 플래시

1. 보드를 USB로 연결
2. 업로드 버튼(→) 클릭
3. 업로드가 안 되면: **BOOT 버튼을 누른 채로 PWR 버튼을 짧게 눌렀다가 떼고**, BOOT를 뗀 뒤 다시 업로드
4. 업로드 후 시리얼 모니터(115200)를 열거나 화면을 본다

## 3. 결과 해석

| 화면 표시 | 의미 | 다음 조치 |
|---|---|---|
| `BOOT / GPIO0` 줄이 초록색 | 아래쪽 버튼이 **BOOT(GPIO0)** 를 누름 | 그대로 사용. 게임 전환 버튼으로 최적 |
| `PWR / TCA9554 P4` 줄이 초록색 | 아래쪽 버튼이 **PWR(AXP2101)** 을 누름 | PWR은 4초에 전원이 꺼지므로, 새 택트 스위치를 GPIO16/17/18에 다는 것을 권장 |
| 둘 다 반응 없음 | 버튼이 보드의 물리 버튼까지 닿지 않음 | 케이스 구조/버튼 높이 조정 또는 배선 필요 |

## 주의

- `PWR` 줄이 반응하는 경우 **4초 이상 누르지 마세요.** AXP2101이 하드웨어로 전원을 차단합니다.
- `BOOT` 줄이 반응하는 경우, **부팅 중**에 누르고 있으면 다운로드 모드로 들어갑니다. 게임 전환은 부팅이 끝난 뒤 2초 롱프레스로 구현하면 됩니다.
- 화면이 안 나와도 시리얼 모니터에 `BOOT PRESSED` / `PWR PRESSED`가 출력됩니다.

## 멀티미터 없이 확인하는 다른 방법

- **PWR 의심**: 전원이 켜진 상태에서 아래쪽 버튼을 4초 이상 누른다. 기기가 꺼지면 PWR.
- **BOOT 의심**: 아래쪽 버튼을 누른 채로 USB를 꽂는다. 다운로드 모드(업로드 대기)로 들어가면 BOOT. 단, 이 방법은 정상 부팅을 막으므로 테스트 스케치가 더 안전하다.
- **육안**: 케이스를 열고 아래쪽 버튼을 눌렀을 때 보드의 어느 버튼이 눌리는지 확인. PWR은 전원 쪽, BOOT은 반대쪽에 있다.
