TamaHub

Waveshare ESP32-S3-Touch-AMOLED-1.75 · Pokémon과 Digimon을 한 기기에, 부팅 메뉴로.

설치 Chrome / Edge 데스크톱

처음 설치할 때는 칩 전체 지우기(Erase)가 필요합니다.
기존에 쓰던 세이브가 있다면 먼저 백업하세요. TamaDigi의 EXPORT, TamaPoke의 세이브 백업 기능을 사용하거나, 설치 전에 기존 펌웨어로 한 번 켜서 저장이 끝난 상태로 만들어 두세요.
설치 중에는 USB 케이블을 뽑지 마세요. 쓰기가 중단되면 부팅이 불가능해질 수 있습니다.
전체 설치 (TamaHub + TamaPoke + TamaDigi) 부트로더 · 파티션 테이블 · 허브 · 두 게임을 각자의 주소에 씁니다.

게임만 업데이트 (세이브 유지)

파티션 테이블과 NVS를 건드리지 않고 해당 슬롯만 다시 씁니다.

허브factory
Pokémonota_0
Digimonota_1

처음 켜면

  1. TamaHub가 뜨고 세 개의 카드가 보입니다: Pokémon, Digimon, Extra Slot.
  2. 카드를 터치하면 해당 게임으로 재부팅합니다. 아래쪽 BOOT 버튼으로도 선택/실행할 수 있습니다.
  3. 게임을 고른 뒤에는 전원을 껐다 켜도 마지막 게임으로 바로 부팅합니다.
  4. 다른 게임으로 바꾸려면 게임 중 아래쪽 버튼을 2초 이상 누른 뒤 놓으세요.
아래쪽 버튼은 BOOT(GPIO0)입니다. 부팅 중에 누르고 있으면 다운로드 모드로 들어가므로, 반드시 게임이 켜진 뒤 길게 누르세요. 전환은 손을 뗀 뒤 실행됩니다.

SD 카드 준비

두 게임의 스프라이트 경로가 겹치지 않도록 게임별 폴더로 분리했습니다. microSD 루트가 아래처럼 보여야 합니다.

/tamapoke/mons/p001.bin
/tamapoke/mons/ps001.bin
/tamapoke/mons/thumbs.bin

/tamadigi/mons/p001.bin
/tamadigi/mons/ps001.bin
/tamadigi/mons/thumbs.bin
/tamadigi/mons/.pack-1 ... .pack-5  (직접 복사 시 없어도 됨)
  • 각 게임 저장소의 tools/sdcard/mons 내용을 위 폴더로 복사하면 됩니다.
  • 예전 /mons 하나만 쓰던 카드라면, 한 게임의 내용을 /tamapoke/mons로 옮기고 다른 게임 것은 /tamadigi/mons로 복사하세요. 파일 이름은 같지만 내용은 다릅니다.
  • TamaPoke는 SD 마운트 실패 시 더 이상 카드를 포맷하지 않습니다.

boot_app0.bin은 0xE000에 쓰지 않습니다. 이 주소는 64 KB NVS 내부입니다. 설치 프로그램은 파트별 오프셋으로만 기록하며, 병합 이미지(offset 0)를 쓰지 않습니다.

문제가 생기면

  • 화면이 검은색: 부팅 중 BOOT를 누르고 있었는지 확인하세요. 다운로드 모드라면 USB를 다시 꽂고 이 페이지에서 재설치합니다.
  • 허브로 돌아오지 않음: 아래쪽 버튼을 2초 누른 뒤 완전히 떼야 전환됩니다.
  • 세이브가 사라짐: 전체 설치(Erase)를 했는지 확인하세요. 게임 업데이트 버튼은 NVS를 건드리지 않습니다.
  • 시리얼 모니터: 115200 baud. 허브에서 1/2/3은 즉시 실행, SLOTS는 상태 출력입니다.
