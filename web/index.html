TamaHub

Waveshare ESP32-S3-Touch-AMOLED-1.75 · Pokémon, Digimon, Naruto, Clock, 내비를 한 기기에, 부팅 메뉴로.

버전 확인 중…

설치 Chrome / Edge 데스크톱

v2 레이아웃은 한 번만 설치하면 됩니다. 세이브는 지우지 않습니다.
이전 버전이 이미 설치되어 있다면 아래 일괄 설치를 한 번만 실행하세요. 선택한 앱이 순서대로 모두 기록됩니다. NVS와 otadata 주소가 그대로라 Pokémon / Digimon / Naruto 세이브가 유지됩니다. Erase는 처음 설치하거나 칩을 완전히 초기화할 때만 사용하세요.
설치 중에는 USB 케이블을 뽑지 마세요. 쓰기가 중단되면 부팅이 불가능해질 수 있습니다.

1. 슬롯 배치 이것만 고르세요

각 앱을 어느 슬롯에 넣을지 고르세요. 허브는 항상 factory에 있고, 앱은 이름표를 스스로 갖고 있어 순서와 종류를 바꿔도 허브가 알아서 표시합니다. 고른 배치는 이 브라우저에 저장되어 다음 방문에도 그대로 남습니다.

내비게이션(TamaNav)은 폰의 BLE 내비 알림을 받아 화면에 턴바이턴만 그립니다. 폰 동반 앱이 없으면 대기 화면에 머물며, 시리얼 `DEMO`로 화면을 확인할 수 있습니다.

설치 계획 슬롯을 고르면 순서가 자동으로 정해집니다.

    위 순서대로 한 번의 설치로 모두 기록됩니다. 앱마다 버튼을 다시 누르거나 포트를 다시 고를 필요가 없습니다.

    2. 일괄 설치

    선택한 구성 일괄 설치 (세이브 유지) 부트로더 · v2 파티션 테이블 · 허브 · 선택한 앱을 순서대로 씁니다. Erase 없음.

    앱만 업데이트 (세이브 유지)

    파티션 테이블과 NVS를 건드리지 않고, 위에서 고른 앱만 각자의 슬롯에 다시 씁니다.

    선택한 앱현재 배치 그대로
    허브만factory
    Chrome / Edge 데스크톱에서만 설치할 수 있습니다.
    처음 설치 / 칩 전체 지우기 (Erase)

    칩 전체를 지우고 v2 레이아웃을 새로 씁니다. 모든 세이브가 사라집니다. 새 기기이거나 세이브를 버려도 될 때만 사용하세요.

    전체 설치 (Erase) 부트로더 · v2 파티션 테이블 · 허브 · 선택한 앱
    Chrome / Edge 데스크톱에서만 설치할 수 있습니다.

    처음 켜면

    1. TamaHub가 뜨고 위에서 배치한 앱 카드가 보입니다. 빈 슬롯은 NOT INSTALLED로 표시됩니다.
    2. 카드를 터치하면 해당 앱으로 재부팅합니다. 시리얼에서는 1–5로 바로 실행할 수 있습니다.
    3. 앱을 고른 뒤에는 전원을 껐다 켜도 마지막 앱으로 바로 부팅합니다.
    4. 허브로 돌아오려면 앱 안에서 BOOT 버튼을 2초 이상 누른 뒤 놓으세요. 짧게 누르면 앱마다 뒤로가기입니다.
    아래쪽 버튼은 BOOT(GPIO0)입니다. 부팅 중에 누르고 있으면 다운로드 모드로 들어가므로, 반드시 앱이 켜진 뒤 길게 누르세요. 전환은 손을 뗀 뒤 실행됩니다. 전투나 미니게임 중에는 짧게 눌러도 빠져나가지 않습니다.

    SD 카드에 스프라이트 넣기 Web Serial

    게임을 실행한 상태에서 USB로 연결하면 스프라이트 팩을 microSD에 직접 넣을 수 있습니다. SD 카드를 뽑거나 PC에 꽂을 필요가 없습니다.

    업로드할 게임이 실행 중이어야 합니다.
    Pokémon은 TamaPoke, Digimon은 TamaDigi, Naruto는 TamaNaruto 화면이 떠 있을 때 연결하세요. TamaHub 화면에서는 SD 업로드가 동작하지 않습니다. 업로드 중에는 전원을 끄거나 USB를 뽑지 마세요.
    구버전 펌웨어는 게임 확인 명령이 없어 연결이 거부됩니다. 먼저 위의 앱만 업데이트를 실행하세요.

    microSD는 FAT32로 포맷되어 있어야 합니다. 카드가 인식되지 않으면 게임을 재부팅한 뒤 다시 시도하세요. 이미 예전 Digimon 빌드라면 위의 앱만 업데이트를 먼저 실행하세요(중단 후 재시도 안전).

    연결 안 됨
    SD: 확인 안 됨

    중간에 끊기면 USB를 다시 연결하고 같은 버튼을 누르세요. 이미 확인된 파일은 건너뜁니다. SD를 포맷했거나 카드를 바꿨다면 를 누르세요.

    SD가 인식되지 않으면 SD 마운트 / 포맷을 누르세요. 정상 카드는 데이터가 유지되고, 인식할 수 없는 카드만 포맷됩니다. 포맷되면 두 게임의 스프라이트가 모두 지워집니다.

    SD 카드 (수동 준비)
    
    
    웹 업로드를 쓰지 않을 때의 방법입니다. 두 게임의 스프라이트 경로가 겹치지 않도록 게임별 폴더로 분리했습니다.
       microSD 루트는 아래와 같습니다.
    
    
    /tamapoke/mons/p001.bin
/tamapoke/mons/ps001.bin
/tamapoke/mons/thumbs.bin

/tamadigi/mons/p001.bin
/tamadigi/mons/ps001.bin
/tamadigi/mons/thumbs.bin
/tamadigi/mons/.pack-1 ... .pack-5  (직접 복사 시 없어도 됨)
    
    
      
      
    • 각 게임 저장소의 tools/sdcard/mons 내용을 위 폴더로 복사하면 됩니다.

          다른 게임 것은 /tamadigi/mons로 복사하세요. 파일 이름은 같지만 내용은 다릅니다.

    파티션 / 주소
    
    
    
      
    이름용도주소크기
    
      
    nvs모든 앱 + 허브 세이브0x900064 KB
    
      
    otadata다음 부팅 앱0x190008 KB
    
      
    factoryTamaHub0x200002 MB
    
      
    ota_0앱 슬롯 10x2200002 MB
    
      
    ota_1앱 슬롯 20x4200002 MB
    
      
    ota_2앱 슬롯 30x6200002 MB
    
      
    ota_3앱 슬롯 40x8200002 MB
    
      
    ota_4앱 슬롯 50xA200002 MB
    
    
    
    
    
      boot_app0.bin은 0xE000에 쓰지 않습니다. 이 주소는 64 KB NVS 내부입니다.
      설치 프로그램은 파트별 오프셋으로만 기록하며, 병합 이미지(offset 0)를 쓰지 않습니다.
      슬롯 배치를 바꿔도 NVS가 그대로라 세이브는 유지됩니다.
    
    
  
    

  
    
    
    문제가 생기면
    
    
      
      
    • 화면이 검은색: 부팅 중 BOOT를 누르고 있었는지 확인하세요. 다운로드 모드라면 USB를 다시 꽂고 이 페이지에서 재설치합니다.
      • 
      
    • 허브로 돌아오지 않음: 아래쪽 버튼을 2초 누른 뒤 완전히 떼야 전환됩니다.
      • 
      
    • 세이브가 사라짐: 전체 설치(Erase)를 했는지 확인하세요. 앱 업데이트와 일괄 설치는 NVS를 건드리지 않습니다.
      • 
      
    • 시리얼 모니터: 115200 baud. 허브에서 1–5는 즉시 실행, SLOTS는 슬롯 상태 출력입니다.
